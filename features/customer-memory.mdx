# Customer Memory

When a customer comes back, your AI agent remembers their earlier conversations: what they asked about, what was done, and anything still open. The customer doesn't have to explain again.

<Note>
Customer memory is a **Pro** feature on ChatterMate Cloud. It isn't part of the open-source edition.
</Note>

## Turning it on

Customer memory is off for every agent until you turn it on.

1. Go to **AI Agents** and open an agent with **Configure**.
2. Open the **Advanced** tab.
3. Turn on **Remember returning customers**.

You need the **Manage Agents** permission to change it. On plans below Pro the switch is locked, with an upgrade link. You can turn it off at any time.

## What the agent remembers

For each earlier conversation, the agent keeps a short note: what the customer wanted, what was done or promised, and anything still to follow up. It remembers the customer's most recent conversations with that agent from the last 90 days.

The agent uses this only where it helps with what the customer asks now, and checks with them before acting on it. Notes are written in English, and the agent still replies in the customer's own language.

## Who counts as the same customer

The agent only remembers someone it can be sure is the same person, so nobody sees another customer's history by typing their email:

| Channel | Remembered when the customer |
| --- | --- |
| **Website widget** | Comes back on the same browser, or confirms their email with a code |
| **WhatsApp, Telegram, Messenger, Instagram, LINE, SMS** | Messages from the same account or number |
| **Email, Slack, API** | Not remembered |

Each agent only remembers its own conversations with the customer.

## Privacy

- Passwords, codes, card, bank and ID numbers, and health details are never kept.
- Memories are encrypted.
- Memories are kept for up to 90 days, and are deleted when the conversation is deleted.

Customer memory doesn't count toward your plan's AI messages.
